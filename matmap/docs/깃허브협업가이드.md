# 깃허브 협업 가이드

## 초기 프로젝트 세팅
1. build.gradle, application.properties, static 등 설정/정적 파일 포함시키기
2. 설정 클래스 (SecurityConfig.java 등) 포함시키기
3. DB (DDL.sql, 샘플데이터.sql 등) 코드 포함시키기
4. main 브랜치에 commit & push


## 초기 프로젝트 받기
1. Git Clone
2. Github URL 지정
  - https://github.com/ALOHA-CLASS/AIOT7-MATMAP.git
3. 폴더 선택


## 나의 작업 브랜치에 머지
1. 브랜치 이동 : VSCODE 좌측 하단 브랜치 버튼 선택
2. 작업할 브랜치 선택 ex) feature/1-project-setup
3. Merge 
  - 소스 제어 > ... > 분기 > 병합 > main
  - ⭐ main -> feature/1-project-setup


## 팀원이 새로 추가한 기능 머지
1. 브랜치 이동 : VSCODE 좌측 하단 브랜치 버튼 선택
2. 가져올 브랜치 선택     : develop
3. 새 변경 사항 다운로드  : pull
4. 작업 브랜치로 이동 : ex) feature/3-global-exception
3. Merge 
  - 소스 제어 > ... > 분기 > 병합 > develop
  - ⭐ develop -> feature/1-project-setup

## 내 작업 개발 브랜치에 머지
1. 현재 브랜치에 적용될  변경 사항 스테이징
2. 커밋 메시지 작성
  ex) feat: 맛집 지도 조회 기능 추가
3. 커밋
4. 푸시
5. Pull Request (PR)
  - ⭐ develop <- feature/1-project-setup
6. Create Pull Request
7.
